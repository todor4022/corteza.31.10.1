1. Run these commands from the repository’s root:

   cp .env.example .env
   openssl rand -hex 24
   openssl rand -hex 32

2. Edit .env:

   - Replace POSTGRES_PASSWORD with the first generated value.
   - Replace AUTH_JWT_SECRET with the second generated value.
   - Keep these defaults to use the demo account:

   SEED_USER_EMAIL=demo@example.com
   SEED_USER_PASSWORD=DemoPassword123!

   The remaining settings can stay as provided. .env is excluded from Git, so each person creates their own.

3. Build and start everything:

   docker compose up -d

4. Open http://localhost:18080 and sign in immediately with:

   - Email: demo@example.com
   - Password: DemoPassword123!

   The Tickets app is available at http://localhost:18080/tickets/
